# 📖 Executive Summary

**CareSphere HMS** is a professionally engineered Hospital Management System developed using advanced **Object-Oriented Programming principles in Python**.  

The system simulates real-world hospital operations including:

- Patient Lifecycle Management  
- Doctor Administration  
- Appointment Scheduling  
- Billing & Financial Tracking  

This project highlights strong software engineering fundamentals, modular design, and maintainable architecture — making it ideal for academic evaluation and professional portfolios.

---

# 🏗️ System Architecture

The application is designed using:

• Object-Oriented Programming  
• Class-based modular design  
• Encapsulation of data  
• Clear separation of responsibilities  
• Structured CLI interaction model  

All logic is organized inside a single primary executable file:

```
HOSPITAL_MANG_SYS.py
```
